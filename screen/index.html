CYD — شاشة عرض بالواي فاي

صورة الكمبيوتر أو الجوال تنتقل للشاشة بلا كيبل

1. الفيرموير

  1. نزّل الملف واحرقه
  2. أول تشغيل: الشاشة تنشئ شبكة اسمها CYD-Setup
  3. من الجوال: اتصل بـ CYD-Setup وافتح 192.168.4.1 واكتب اسم شبكتك وكلمتها
  4. بعد الحفظ تعيد التشغيل وتتصل، ويظهر على الشاشة IP مثل 192.168.1.7
تنزيل CYD-Screen-WiFi-v2.0.bin

بعد الفلاش لازم تشوف SCR 1.1 بأسفل الشاشة الفاضية.

2. من الجوال

  1. ثبّت التطبيق وافتحه
  2. اكتب IP الشاشة واضغط ابدأ العرض، واسمح بتصوير الشاشة
  3. صورة جوالك تنعرض على CYD فوراً
تنزيل CYD-Mirror-v1.0.apk

3. من الكمبيوتر

  1. pip install pillow pyserial
  2. python cyd_screen.py --host 192.168.1.7
تنزيل cyd_screen.py 
python cyd_screen.py --host 192.168.1.7 --fps 5
python cyd_screen.py --host 192.168.1.7 --rotate 90

ملاحظات صريحة

الجوال يرسل صورة JPEG مصغّرة 240×320. الوضوح متوسط والسرعة ٦-٨ صورة بالثانية على واي فاي جيد، فالشات والجداول والصور ممتازة، أما الفيديو والألعاب فما راح تكون سلسة.

إذا ضاع الاتصال، الشاشة ترجع تعرض الإشعارات تلقائياً بعد ثواني. وإذا بغيت تغيّر الشبكة، امسح الإعدادات من الشاشة بإعادة الفلاش مع محو البيانات.
