CYD — شاشة عرض من الكمبيوتر

الشاشة تصير شاشة صغيرة تعرض صورة من الكمبيوتر عبر كيبل USB

1. الفيرموير

  1. نزّل الملف واحرقه بنفس الطريقة السابقة (esp flashing page)
  2. بعد الفلاش لازم تشوف SCR 1.0 بالشاشة الفاضية
تنزيل CYD-Screen-v1.0.bin

2. برنامج الكمبيوتر

  1. افتح CMD واكتب: pip install pillow pyserial
  2. نزّل الملف هذا بمجلد
  3. شوف رقم المنفذ من Device Manager تحت Ports (مثل COM3)
  4. شغّل: python cyd_screen.py --port COM3
تنزيل cyd_screen.py 
python cyd_screen.py --port COM3 --fps 4
python cyd_screen.py --port COM3 --rotate 90      # إذا الشاشة نائمة على جنبها
python cyd_screen.py --port COM3 --region 0,0,1200,800   # جزء من الشاشة

شنو تتوقع

  1. الشاشة تعرض صورة مصغرة من شاشتك باستمرار
  2. السرعة ٣-٤ صورة بالثانية عبر USB — كافية للشات والجداول والساعة، مو كافية للفيديو
  3. إذا ما وصلت أي صورة، ترجع الشاشة تعرض الإشعارات تلقائياً بعد ٤ ثواني
الفيديو والألعاب ما يشتغلون بسلاسة على هذه الشاشة — 240x320 وسرعة USB ما تكفي. الشات والجداول والعدادات ممتازة.
