Future Rotate

برنامج صغير يدوّر شاشة ويندوز 11 بضغطة — يشتغل على أي معالج Intel أو AMD

النسخة بالفأرة (الأسهل)

  1. نزّل الملف وشغّله
  2. تفتح نافذة فيها أربع أزرار: عادي 0° / طولي 90° / مقلوب 180° / طولي 270°
  3. اضغط الزر اللي تريده، الشاشة تدور فوراً
تنزيل rotate-gui.exe

إذا ويندوز حذّر من الملف: اضغط More info بعد Run anyway، لأنه برنامج بلا شهادة توقيع.

نسخة الاختصارات

  1. نزّل rotate.exe وملفات الـ bat الأربعة بنفس المجلد
  2. كل ملف bat يدوّر الشاشة لزاوية معينة بضغطة مزدوجة
  3. تقدر تسحب أي bat على سطح المكتب
تنزيل rotate.exe

من سطر الأوامر: rotate.exe 90 أو 0 أو 180 أو 270

بدون أي برنامج

  1. جرّب الاختصار Ctrl + Alt + سهم — إذا كانت درايفرات إنتل مفعّلة يشتغل مباشرة
  2. أو: سطح المكتب بزر يمين ← Display settings ← Display orientation

إذا Ctrl+Alt+الأسهم ما يشتغل عندك، برنامج Future Rotate هو البديل.
