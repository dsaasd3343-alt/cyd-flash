محطة طقس CYD — مع إشعارات الجوال من Pushbullet

1. وصّل الجهاز (CYD / ESP32) بكيبل USB للكمبيوتر
2. اضغط زر التثبيت تحت، ووافق على اختيار المنفذ
3. الجهاز يبحث عن الشبكات القريبة ويعرضها - اختر شبكتك واكتب كلمة السر
4. حمّل تطبيق Pushbullet على جوالك وسجّل دخول
5. انسخ الـ Access Token مالك من pushbullet.com وأدخله بالخانة تحت
متصفحك ما يدعم الفلاش من الويب. استخدم Chrome أو Edge على كمبيوتر أو أندرويد.

الخطوة الأخيرة: رمز Pushbullet (API Token)

تلقاه هني: pushbullet.com ← Settings ← Access Tokens ← Create Access Token (يبدأ بـ o.)
بعد ما تكتبه وتضغط إرسال، يوصل للجهاز عن طريق كيبل الـ USB ويبدأ يشتغل مباشرة.

يتطلب Chrome أو Edge (كمبيوتر أو أندرويد). آيفون/سفاري ما يدعم. إذا تريد تغيير الواي فاي أو الرمز بالمرّة الجاية: وصّل الجهاز USB وافتح هذي الصفحة. الرمز يحفظ بجهازك فقط، وكل جهاز يرتبط بحساب صاحبه.
