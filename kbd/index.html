Future Keyboard

كيبورد على الجوال يطبع على الكمبيوتر عبر الواي فاي — عربي وإنجليزي

1. على الكمبيوتر

  1. نزّل ملف السيرفر من الزر تحت
  2. افتح CMD بمجلد التنزيل واكتب: python future_keyboard.py
  3. راح يطبع لك IP مثل 192.168.1.5 — احفظه
تنزيل future_keyboard.py

إذا طلع خطأ python not found استخدم py بدل python. يحتاج Python مثبت، وما يحتاج أي مكتبات إضافية.

2. على الجوال

  1. نزّل التطبيق وثبّته
  2. اكتب IP الكمبيوتر واضغط اتصال
  3. اكتب بأي لغة — الحروف تنتقل للكمبيوتر حرف بحرف
  4. تحت فيه أزرار Enter وTab والمسح والأسهم والنسخ واللصق وAlt+Tab
تنزيل Future-Keyboard-v1.0.apk

الجوال والكمبيوتر لازم على نفس شبكة الواي فاي. إذا النت عندك شبكة ضيوف، خليها شبكة عادية.

ملاحظات

  1. الحروف تروح للنافذة المفتوحة حالياً على الكمبيوتر، فانتبه وين المؤشر
  2. مفاتيح Ctrl وShift تشتغل كمفتاح مزدوج: فعّلها وبعدها اضغط الحرف
  3. ما يشتغل عبر البلوتوث — يشتغل عبر الواي فاي لأن أندرويد ما يسمح للجوال يكون كيبورد بلوتوث
